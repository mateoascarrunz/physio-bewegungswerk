# Physio Bewegungswerk website

Vue 3 and Vite website for [physio-bewegungswerk.ch](https://www.physio-bewegungswerk.ch), hosted on Vercel. Content comes from the Strapi CMS in [Strapi-physio-CH](https://github.com/mateoascarrunz/Strapi-physio-CH).

```sh
npm ci
npm run dev
```
